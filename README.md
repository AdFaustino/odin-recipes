# odin-recipes
*Project Introduction*
This project is a basic recipe website.
This project practiced my foundation knowledge in HTML. It also helped me with getting used to Git commands.
The website consist of a main index page which have links to 3 recipes:
- Filipino Chicken Adobo
- Filipino Ground Beef Adobo
- Lumpiang Shanghai
Each recipe page includes a link back to index, image of the finished dish, description, ingredients, and steps.
It took me 3 hours to finish this.
